# team-sub

A sideline substitution tracker for volunteer youth rec soccer coaches. Plain HTML, CSS, and JavaScript. No framework, no build step, no backend. State persists in `localStorage`.

The app is built and working. `index.html`, `app.js`, and `styles.css` exist and carry the whole game flow: roster setup, lineup, live game, and full time.

## Read these before designing or building UI

- `PRODUCT.md` — durable product truth: users, purpose, constraints, and the facts left deliberately undecided.
- `.impeccable/surfaces/index-html.md` — the confirmed surface brief for the whole game flow, including the `## Direction contract` that holds the chosen visual world.

## The visual world is already chosen

A direction round ran and the user confirmed the result. **Do not run another one.** The build finished and the documenter ran, so `DESIGN.md` now exists and was derived from the shipped artifact. **`DESIGN.md` is the visual authority.** The `## Direction contract` in the surface brief is kept as the record of what was chosen, not as a live spec to build against.
